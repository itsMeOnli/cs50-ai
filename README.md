# CS50's Introduction to Artificial Intelligence with Python

This repository contains my solutions and projects for **CS50's Introduction to Artificial Intelligence with Python** by Harvard University.

The course introduces fundamental concepts in artificial intelligence including:

* Search algorithms
* Knowledge representation
* Uncertainty and probability
* Optimization
* Machine learning
* Neural networks

Each week focuses on a different AI concept and includes programming projects implemented in **Python**.
